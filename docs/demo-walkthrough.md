# Demo walkthrough script (3–5 minutes)

Plan §12B asks for a short video that follows the acceptance tests in order. This is the script; the
video itself is recorded by the owner. Everything runs locally (`npm run dev`, store at
`http://store.localhost:3000`, admin at `http://admin.localhost:3000`) with the demo seed
(`npm run db:seed`); demo staff use the password in the README (development only).

| Time      | Show                                                                                                                                                                                                                                                                                                                                            | Acceptance test                            |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 0:00–0:20 | Store home: banners, collections, new arrivals, categories. Type `kur` in the search box: suggestions appear (C14); arrow down, Enter opens the product.                                                                                                                                                                                        | —                                          |
| 0:20–1:10 | Search `kurta`, filter by an attribute (facet counts), sort by price. Open a product, check a pincode (`411001`), choose a size, **Add to cart**, apply `SAVE10`, **Checkout** with Cash on Delivery.                                                                                                                                           | 1. Find → cart → order                     |
| 1:10–1:30 | The order page: items, payment, shipments and the **Messages** card (simulated SMS "We have received your order …", C38).                                                                                                                                                                                                                       | 1                                          |
| 1:30–1:50 | Admin **Orders**: the new order is there, PLACED, with its reservation (Inventory shows reserved units).                                                                                                                                                                                                                                        | 1                                          |
| 1:50–2:20 | Explain (or show `docs/test-evidence.md`): stock is re-checked at checkout (409 when it ran out) and 10 parallel checkouts for 3 units reserve exactly 3; the same `Idempotency-Key` ×5 gives one order.                                                                                                                                        | 2. Stock never negative · 3. No duplicates |
| 2:20–3:10 | Admin order: **Confirm** → **Mark packed** → **Create AWB** → **Download label** → **Simulate pickup scan**, **Mark delivery failed** → **Return to origin** → **Receive and restock**: payment FAILED, stock back. | 3:40–4:30 | Optional tour: **Settings** → "Warehouse for each order: nearest to the delivery pincode" (Wave 16); **Returns** queue; **Staff**; **Search index**; **API docs** (Swagger UI).                                                                                                                                                                 | P1/P2 features                             |

Tips: use a fresh browser profile; OTP sign-in shows its code in a popup in development
(`OTP_DISPLAY_IN_UI`); Elasticsearch must be running for suggestions from the index (otherwise the
PostgreSQL fallback answers).
